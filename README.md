# Blog ERH V2.0.0

This repository contains the installable Elite Range Hood blog Skill.

## What another operator gets

After installation, the operator enters one English topic. The Skill researches and produces a local review package whose primary outputs are:

- a linked English Word document;
- Shopify-safe HTML with verified contextual internal links;
- one `1774 × 887` featured image and two `1536 × 1024` body images, preferably approved Elite Range Hood project photography;
- English and Chinese source copies, SEO metadata, sources, image provenance, a local preview, and validation results.

The package follows the repository's V10 linked Word and HTML output standard. Creating files does not publish to Shopify. Visible publication requires the exact approval phrase documented in the Skill.

## Install with Codex

Ask Codex to use the Skill installer with:

- repository: `vickyfobes-ops/Blog-ERH-V2.0.0`
- path: `blog-erh-v2-0-0`
- branch: `main`
- installation name: `blog-erh-v2-0-0`

Then start a new task and enter:

```text
使用 $blog-erh-v2-0-0，选题是：How to Choose a Custom Range Hood
```

The store profile is non-secret. Authentication is never included in the repository.
