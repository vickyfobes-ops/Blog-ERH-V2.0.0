# Elite Range Hood 博客自动化交接包

交接版本：2026.11.04。Skill 名称保持 `blog-erh-v2-0-0`，输出以 V10 为标准。

## 安装和调用

推荐将整个文件夹复制到对方电脑本地，在 Codex 中打开该文件夹，发送 `01-给Codex的安装提示词.txt` 里的整句。Codex 会验证文件、安装 Skill，并在已有版本时备份更新。相同版本重复安装不会产生额外备份。

也可双击 `Install-Windows.cmd` 或 `Install-macOS.command`。这些入口需要 Python 3.10+；macOS 会优先使用已有的 Codex 内置 Python。如果系统阻止脚本打开或没有 Python，使用上述 Codex 安装方式，由 Codex 定位可用运行环境。

安装后在下一条消息输入：

```text
使用 $blog-erh-v2-0-0，选题是：How to Choose a Custom Range Hood。
```

替换成自己的英文选题即可。旧任务仍显示旧版规则时，新建任务调用。每篇文章无需重新安装。

## 输出标准

- 带可点击内链的完整英文 Word、Shopify HTML，以及完整中文审阅稿。
- 至少两个已核验的产品页链接，Word 与 HTML 的链接保持一致。
- 一张 1774 × 887 封面、两张 1536 × 1024 正文图。优先使用获准使用的品牌真实摄影，保持产品和房间比例。
- SEO、来源、图片出处、本地预览和校验结果。

初次本地交付的 Shopify HTML 中，图片地址可能仍是上传占位符；Word 和本地预览会显示完整图片，内链已可点击。获准上传图片后才替换为实际 Shopify CDN 地址。

## 包内文件

- `blog-erh-v2-0-0/`：完整可安装 Skill，含规则、品牌资料、模板、依赖清单、生成与校验脚本。
- `README.md`：GitHub 安装与运行条件说明。
- `01-给Codex的安装提示词.txt`：本地安装/更新指令。
- `02-选题调用示例.txt`：日常调用指令。
- `V10参考样例/`（内部完整包提供）：用户指定的 HTML、Word 和三张图片；用来对照排版和图片标准。示例事实和链接是历史内容，新文章仍需重新核验，不能直接当成当前事实。
- `PACKAGE-MANIFEST.json`、`verify_package.py`：版本、来源提交及文件完整性校验。

## 必要运行条件

使用支持本地 Skill、文件和命令工具的 Codex，并具有联网研究能力。生成脚本需要 Python 3.10+、Pillow 和 python-docx，优先使用 Codex 内置环境；缺失时按 Skill 说明在当前工作区创建独立环境。Word 完成视觉检查需要文档渲染能力；采用 AI 图片回退方案时需要图像生成能力。

本包不包含 Codex 应用、跨操作系统 Python 运行时、账号或登录信息。只有要求上传/发布时，操作员才需要自己的 Shopify 权限并登录；生成本地文稿无需 Shopify 登录。正式发布使用“审核通过并发布”。

## 更新和恢复

新装和更新使用同一入口。旧版会完整保留在 Codex 配置目录的 `skill-backups` 中，安装日志会显示具体位置；安装激活失败时会恢复旧版。文章输出保存在工作区，不放进 Skill 目录。
